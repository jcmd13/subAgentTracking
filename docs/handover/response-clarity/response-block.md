## Response format
For any response longer than ~10 lines, start with:
**Answer:** one line (yes/no/recommendation)
**Decision needed from you:** none | the choice, options, my pick + why
**Risk:** low/med/high, the one thing most likely to bite
**Done / Not done / Not verified:** be explicit about what was assumed or untested
Then details. Respect explicit word budgets ("<=150 words").
When parking a session: suggest a descriptive session title and end with a 3-line re-entry note (state, next action, open question).
